# 探员大厅玩法优化验收

日期：2026-10-15（Asia/Singapore）。本轮在八案调查与难度调整的基础上，完善出勤准备、编队选择及实际规则的一致性。既有八案通关、五名 agent 试玩与难度预算记录保留各阶段结果；下面的大厅 QA 是预置档案配合真实处理器的功能验收，不是新一轮盲玩或真人试玩。

## 玩法调整

- 简报默认显示出勤准备：逐人展示专业观察、首检优惠和未分配专长，可切换到全息编组。
- 开局 AP 使用与实际开案相同的科技、有效库存装备及当前支援效果；同时显示开局指挥点，以及应急预案触发需要的 1 CP。零库存装备不会虚增预览。
- 查看探员与设置主探员分别操作。部署使用明确指定的主探员，不跟随正在查看的角色变化。
- 三种编队预设先比较再应用：显示能力增减、行动偏好变化、协同新增/失去和上限退点；应用后可单次撤回专长及偏好。撤回不会覆盖主探员、指挥方案或核心席位。手动调整专长、偏好、替换核心或恢复保存配置后，旧撤回失效。
- 每人专长预算保持 20 点，能力上限保持 40。替换核心与保存编队前均执行归一化，避免属性溢出却仍消耗专长点。SOVEREIGN-01 应用逻辑预设时退回 7 点，可另行分配。
- 技能区分别说明等级不足、前置未装备、可装备和已装备；支持一键装备合法前置链，卸下前置时级联卸下后续，非法操作及只读状态均拒绝写入。保存继续使用串行同步与失败回滚。
- 行动偏好、协同和技能说明标出手动调查的实际用途。旧版自动调查效果不承诺自动进入手动模式；手动调查仍由玩家选择方法、执行者和证据。
- 手机部署按钮占完整一行，大厅各面板内部滚动，修复聚焦按钮后整体滚偏和顶部裁切。指南与核心替换弹窗支持焦点约束；指南关闭后焦点回到编队工具按钮。“调整专长”直接打开对应探员属性页。

## 新案规则与兼容

新建调查版本 2 案件记录 `investigation.preparation_revision: 2`，继续使用 `run_json`，无需数据库迁移。

| 项目 | 新案实际效果 |
| --- | --- |
| 对应逻辑/观察/黑客达到 24/40 | 解锁该能力对应的专业观察，补充已发现物件的分析 |
| 任一逻辑/观察/黑客达到 30/40 | 该探员每案首次收费核验免 1 AP；不保证核验方法正确 |
| 紧急节流 | 2 点信用可抵扣核验、证据问询及专属核验，报价与扣费一致 |
| 精准取证 | 首次有效关系恢复 1 CP，仅一次；满额后不能留待刷取 |
| 幽灵协议协同 | 危机导致的混乱增量降低 20%，仍需选择并支付应对费用 |

首检优惠、扫描器和节流按规则依次使用，免费复查不消耗额度；错误核验会消耗已使用的优惠。专属操作保存报价，避免获取选项期间触发应急预案后费用变化。专业观察及优惠均不跳过证据正确性判定。

没有 preparation 标记的旧版本 2 运行继续沿用旧能力门槛、收费和指挥行为；版本 1 规则冻结。新规则不会回写正在进行的已付费案件。大厅明确提示能力门槛适用于新建调查；活动案件预览保持只读。

## 界面与真实部署 QA

使用独立 5197 临时本地服务器及内存 SQLite，通过真实 `handleProfileFunction` 执行保存与开案。档案预置三名 starter、已拥有 SOVEREIGN-01、等级 4，以及科技 +2 AP 与库存为 1 的已装备道具 +3 AP；未使用真实账户、未购买核心。1280×720 桌面与 390×844 手机视口检查如下：

1. 选择预设只展示比较；应用后能力达到 40/30/40、首检优惠就绪；撤回恢复原专长和偏好。
2. 查看 NEXUS 不改变主探员；明确指定 CIPHER-47 后，替换已拥有核心与保存均保留该主探员。
3. SOVEREIGN-01 的预设退回 7 点，比较与属性页结果一致。
4. 技能前置原因可查看，一键装备后真实服务端同步；从技能页点击调整专长会打开属性页。
5. 指南打开后焦点进入弹窗，Escape 关闭后回到编队工具；手机部署按钮正常显示，预设协同可展开阅读。
6. 实际部署隐秘预设后，真实新案确认主探员为 CIPHER-47、开局 25 AP、preparation revision 为 2。
7. 英文只读界面可查看，但主探员、应用、撤回、部署、指挥及属性增减均禁用。开案消耗道具后，未来新案预览为 22 AP，与剩余科技效果一致。
