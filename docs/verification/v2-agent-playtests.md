# 五名独立 agent 模拟试玩

本页保留调难前实际经历。后续已按这些反馈完成[难度调整](investigation-difficulty.md)：降低新案危机费用、一次附件免费补正、可选旁证提示及手机报告折叠；下表不是调整后复测。

试玩开始：2026-10-14；最终整理：2026-10-15（Asia/Singapore）。用户要求“先设计几个agent来玩”。五名参与者未继承开发对话或谜底，仅通过可见界面使用正常操作。每人独立本地运行、默认队伍、20 AP；不使用生产账号、真实付费或云端奖励。详见[协议](v2-agent-playtest-protocol.md)。

这是一轮边玩边修的形成性检查，保留修复前的错误经历。它不是冻结版本盲测，也不是五名真人研究；不同案件、工具等待及环境暂停使通关时长不能直接比较。首线索时间包含教程阅读、agent思考和浏览器工具延迟。

## 发现的问题与处理

| 原始观察 | 最终处理与证据 |
| --- | --- |
| 可访问树把Canvas备用文本显示成“设备无法3D” | 改为中性场景说明；真实渲染失败仍保留错误边界。P03截图实际显示3D房间及人物。 |
| 问询已保存，却因新危机出现而刷新下一组选项失败 | 先提示处理危机；普通响应及丢响应恢复回归通过，P04后续危机实际复查成功。 |
| 有明确时钟或独立旁证的合理关系被误拒 | 新增19条有来源的时间关系及八案隐藏支持，共75条命题；保留方向校验和错误关系一次性惩罚。权威专项47/47、内容专项61/61通过。 |
| 目标只有对象名称，玩家不知道隐藏物件在哪 | 公开可达对象附中英区域，目标指明区域；深潮入口优先提示当前可调查对象，避免指向门后的前置。 |
| 驳回报告和错误连线成本事先不清 | 报告显示当前AP对应的驳回成本及首次错误指控风险；关系界面说明无AP消耗和首次错误混乱+3%。真实组件回归覆盖20/5/0 AP与两种语言；P03实际截图确认动态成本。其反馈成本在长表单底部，收尾修改将成本移到结论选择之前。 |
| 标体力−10%，执行者实际净−6% | 明确每回合先全队恢复4%，执行者再扣10%；百分比标为体力。P03实际观察到50→44，其他队员50→54。 |
| 新版还有“执行循环”旧引导，选探员缺选中状态 | 新版改为逐对象手动调查与四维报告；增加aria-pressed与报告字段可访问名称。 |
| 报告“缺机会/时间线”反馈不足以指导修正 | 解释各维度需要证明的职责，不列未发现证据或正确答案；三个已结案参与者均能自行补附件后通过。交叉审阅另发现公开职责只在驳回后显示，收尾已把`dimension_guidance`放到首次报告的各组证据之前；新增SSR回归先失败后通过。 |
| 英文危机夹杂中文词条；延期说明暗示可免费复查解除 | 版本2使用已取得证据的英文名称；延期明确截止回合后信誉−5/混乱+5，免费复查不取消后果。 |

P01、P02、P04都需要一次报告修正，说明“结论正确”与“证据覆盖完整”仍是主要学习点；此结果不能包装成首次提交成功。当时危机保全3 AP明显压缩可选证词预算；后续新案改为2 AP。八案15 AP自动路线包含全部八项检查、六段证词和专属核验，并非最短主线；该基线采用免费危机选项，与模拟玩家实际花费分别记录，不能互相替代。

独立安全复查同时关闭旧的无状态`detectiveRules`入口，避免用伪造客户端案件查询私有结果。已登录固定410、未登录401、非POST405；24个JWT/SQLite探测证明运行、revision与操作账本未变。版本1付费案件仍通过`playerRun`按冻结规则继续。

页面热更新/工具中断后，P05与P03通过正常入口恢复原AP、回合与线索数，没有新开案件或重置进度。重复引导、页内选择丢失与工具长等待记录为环境观察，现有证据不足以认定权威存档错误。

P03未使用核验提示、没有失败核验或错误关系；权威日志确认8次物件检查和专属核验都成功。两次危机分别花费3AP与2AP，11次推进共11AP，余额4AP与记录一致。最初概要中“错核验一次”的误记已按完整日志纠正。

仍保留的界面摩擦：手机报告四组重复证据较长，字幕区域需要内部滚动，介绍页仍以首案作主题，而继续调查显示本次实际案名；结案后连续晋升遮罩打断静态经验明细。它们没有造成此参与者失败或存档丢失，作为后续体验改进记录，未擅自改变结算或调查流程。

收尾界面修改已用单独QA夹具实际复查390×844布局：[费用置顶](v2-report-guidance-mobile-top.jpg)、[证据职责说明](v2-report-guidance-mobile.jpg)。该QA开局0条证据，仅查看公开报告，不提交或推进调查，不计作第六名参与者。两种语言及版本1保持由SSR测试核验；最终完整测试818/818通过。
