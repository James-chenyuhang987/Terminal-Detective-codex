## 从谨慎新玩家视角的改进建议

1. 报告缺维度时，把“缺少哪类逻辑连接”说具体。例如 Lvl_01 解释需要把脉冲操作和案发监控中断连接；Lvl_03 解释为何必须同时有离岗目击与门侧影像，而活体部署为何不够。只重复一般维度定义会让人转向多勾证据。
2. supports 的失败反馈应针对材料事实与关系类型。P01 两条 EMP 相关支持关系有自然语言依据，反馈却讲严格先后；若游戏只收某种命题，需让玩家理解其粒度。
3. 将选项的 10 体力毛成本与“回合末全队恢复 4”同时展示，减少第一步净扣 6 的疑惑。免费背景“不推进回合、不恢复体力”的说明很清楚，应保持这种明确度。
4. 保留身份与行动的边界文案。复制卡不能指认持卡人、到场不能证明部署、老板责任不等于现场行为，这些提醒有效阻止我直接归责。
5. 免费背景、可固定说法、之后抵扣证据核对的流程可理解且实测兑现；其作用是保存说法，而不是省总 AP，固定阶段还额外推进一回合并加混乱。新玩家应能在付费前看清这个交换。

本轮不能评价画面可读性、拖拽关系板、浏览器弹窗、键盘操作、移动布局或真实玩家耗时。CLI 自动维护 revision 与操作 ID，且本地工具审批带来明显等待，墙钟时长不能直接作为关卡 UI 的游玩时长。
