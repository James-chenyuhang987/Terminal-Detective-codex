# 审讯策略与报告解释优化 · 2026-10-15

本轮继续落实“系统承担专业判断，玩家选择调查方向”的定位。具体交付为八案审讯策略和报告证据解释，不改变原有谜底、报告通过条件、评分或结算奖励。本轮未提交、推送或部署。

## 玩家可见变化

| 操作 | 新案件行为 |
| --- | --- |
| 了解背景 | 免费获得人物背景，记录到调查档案；不消耗 AP/体力，不推进回合，也不恢复资源 |
| 固定具体说法 | 付 1 AP，按报价消耗体力并推进一回合，固定一段人物原话；混乱风险预先显示 |
| 出示证据并核对 | 系统匹配已取得证据并取得补充证词；此前为同一人物、同一阶段固定说法所付的 1 AP 抵扣本次对峙，仍消耗报价体力并推进回合 |
| 免费复查 | 重复看背景、已固定说法或已完成证词不再收费、不改变合作度、不增加混乱、不消耗技能额度 |
| 查看材料作用 | 报告每组附证可展开看这份材料实际证明的范围，不自动选择结论或改写附件 |
| 查看本次附件判定 | 系统解释采用的支持依据与保留的背景附件；证据不足时不透露未取得的材料或正确答案 |

明确追问是可选的调查过程，不是新主线门槛。与直接出示已有证据相比，它提前取得可核验的原话，增加一次体力消耗及回合风险；AP 抵扣避免为同一问题重复支付行动点。免费背景不能刷恢复、拖延危机或领取证据。

八案三名 NPC 各两段，共 48 组背景、具体说法及阶段提示，均有中英版本。背景与固定说法不提前替代证据对峙后的改口；无辜者的说明用于澄清事实。对峙后保存原话与补充，调查档案、对话历史和结案回顾可复查，并明确人物说法不等于客观事实。

八案 64 份普通材料的报告说明逐份撰写，区分身份、权限、行动、时间和责任的证明边界。允许附更多背景材料；不因多附惩罚玩家，也不把背景材料算作额外的结案支持。完整链只集中解释系统采用的材料，避免四组报告重复堆叠全部正文。

## 版本与权威规则

- 新运行增加 `interview_revision = 1`、`interview_records`、`report_explanation_revision = 1`，使用现有运行 JSON，无 D1 表迁移。
- 新行为还要求现有 `case_design_revision = 1`。缺失、未知或类型错误的标记继续走原规则，不升级已经开始的案件。
- 追问抵扣来自已记录的该人物、该阶段说法；不能转给其他人物、留到下一阶段或跳过原证据前置。指挥额度在该抵扣之后使用。
- 报价由服务端生成；执行继续通过原有 revision、操作 ID、会话锁和事务。提交后断线重试仍只收费一次，免费背景和付费追问均覆盖了刷新恢复。
- 报告解释只描述已获、已附材料。正确结论及原支持路线仍由原裁定逻辑检查，错误结论不会因为附件齐全而被说成结案通过。
- 修复一项已有并发测试的错误假设：并行请求的第一个不保证是实际提交成功者，操作 ID 复用应检查实际获胜请求。运行时并发规则未因此放宽。
