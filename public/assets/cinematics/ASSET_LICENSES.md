# Cinematic 3D asset manifest

The three GLB props in this directory are original, code-generated assets created for Terminal Detective:

- `terminal-console.glb`
- `evidence-scanner.glb`
- `security-camera.glb`

They contain primitive geometry and materials only. No external models, textures, fonts, HDRIs, or third-party copyrighted content are embedded. They may be distributed with this project under the same terms as the project itself.

Regenerate them with `npm run assets:cinematics` after installing project dependencies.
